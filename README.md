# LazyDB
A TUI based database browser and editor.

<img width="1919" height="1004" alt="image" src="https://github.com/user-attachments/assets/585db8cf-8279-409f-a521-aa8ec1d89157" />

## Install
```bash
# clone this repo
git clone https://github.com/rutwikhdev/lazydb && cd lazydb

# Install
# make sure golang is installed and go/bin is in your path
go install . 

# Run
lazydb
```

## Supported Databases
- SQLite
- Mysql/Mariadb
- PostgreSQL

## Supported Operations
- [x] View table and single record
- [x] Insert record
- [x] Update record
- [x] Delete record
- [x] Column search
- [ ] Fuzzy search
- [ ] Custom fetch queries
